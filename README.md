# 家庭厨房 (Family Kitchen) - 微信小程序

家庭厨房是一款专为家庭设计的“点餐与记账”微信小程序。它不仅能帮助家人规划每天的菜单，还能记录家庭的伙食开销。经过全新升级，项目现已支持**多租户（多家庭）架构**，不同的家庭可以在同一套小程序中拥有各自完全隔离的私密空间。

## 🌟 核心特性

- **👨‍👩‍👧‍👦 多家庭账号隔离**：完整的引导流程。新用户可自由选择“创建家庭”或“加入现有家庭”。通过 6 位专属邀请码，轻松拉家人入伙。
- **🛒 全家共享购物车**：同家庭内的成员在点餐时，购物车是**云端实时共享**的。爸妈负责加菜，孩子负责提交，极大地增加了家庭互动的乐趣。
- **📖 自定义在线菜谱**：不仅支持系统内置菜谱，家人还可以随时在手机上“新建菜谱”，拍照上传拿手好菜的封面，并记录独家做法和用料。
- **💰 在线快捷调价**：物价有波动？在菜品详情页随时点击编辑（✏️）图标，即可同步更新云端菜价，保证后续记账精准无误。
- **📊 智能消费与偏好统计**：除了按周、月、年统计家庭伙食开销，还能自动计算并生成“最爱菜品 Top 10”排行榜。
- **🍜 丰富的菜品分类**：支持特色、冷菜、热菜、汤以及**主食**等常用中式餐饮分类。

## 🛠 技术栈

- **前端**：微信小程序原生开发 (WXML, WXSS, JS)
- **后端服务**：微信云开发 (CloudBase)
  - 云数据库 (Cloud DB)
  - 云函数 (Cloud Functions)
  - 云存储 (Cloud Storage - 用于存储菜品图片)

## 🚀 从零开始部署指南 (适合新手)

本项目深度依赖【微信云开发】(CloudBase)，因此部署过程无需购买服务器和域名，也无需配置繁琐的后端环境。请完全按照以下步骤操作，即可跑通全流程：

### 第一步：准备工作与导入项目
1. 下载并安装最新的 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 使用微信扫码登录开发者工具。
3. 点击 **“导入项目”**，选择本项目的根目录。
4. **AppID**：必须填入您自己注册的小程序 AppID（如果您没有，前往 [微信公众平台](https://mp.weixin.qq.com/) 注册一个“小程序”账号即可获取）。*注意：不能使用测试号，测试号无法开通云开发。*

### 第二步：开通并初始化云开发环境
1. 在微信开发者工具的顶部工具栏，点击带有云朵图标的 **“云开发”** 按钮。
2. 在弹出的窗口中点击 **“开通”**，同意协议后，创建一个免费的基础云环境。
3. 创建成功后，您会在云开发控制台的“概览”页面看到一个 **环境 ID (EnvID)**（格式类似 `cloud1-xxxxxx`），请把它复制下来。
4. 回到代码编辑器，打开 `miniprogram/app.js` 文件，找到 `onLaunch` 生命周期中的 `wx.cloud.init` 这一行。
5. 将 `env: 'cloud1-xxxxxx'` 替换为您刚才复制的真实环境 ID。

### 第三步：初始化云数据库与安全规则 (⚠️ 核心步骤)
如果不建表，代码运行时肯定会报错！请在云开发控制台点击顶部菜单的 **“数据库”**，然后依次执行以下操作：

1. **手动建表**：点击左侧列表上方的 **➕添加集合** 按钮，依次创建以下 5 个集合：
   - `users` (存储用户基本信息与所属家庭)
   - `families` (存储家庭信息、成员与邀请码)
   - `dishes` (家庭专属菜谱库)
   - `orders` (历史订单与账单记录)
   - `cart` (全家共享购物车)
2. **放开数据权限**：为了让同一家庭下的成员都能自由新增菜单和订单，请依次点击上述刚刚建好的 5 个集合，选择右侧的 **“权限设置”** -> 选择 **“自定义安全规则”**，将代码框里的内容替换为以下代码并点击确定保存：
   ```json
   {
     "read": true,
     "write": true
   }
   ```
   *(注：真实上线后为了绝对的安全，建议依据 `doc.familyId == auth.openid` 编写更严格的安全规则)*

### 第四步：部署云函数
本项目包含三个负责核心鉴权与建群逻辑的云函数。如果未部署，会导致无法登录和创建家庭。

1. 在开发者工具左侧的文件树中，找到 `cloudfunctions` 文件夹。
2. **绑定云环境**：右键点击 `cloudfunctions` 文件夹 -> 点击 **当前环境** -> 选择您刚才创建的云环境（此时文件夹名称后会多出环境名称）。
3. 依次右键点击内部的 `login`、`initFamily`、`joinFamily` 这三个文件夹，选择 **“上传并部署：所有文件”**。
4. 看到右下角提示上传成功即可。

### 第五步：初始化默认菜单数据 (可选)
当用户创建新家庭时，系统会自动将“公有菜谱”克隆到他家。什么是“公有菜谱”呢？
1. 打开云开发控制台的 **数据库**，进入 `dishes` 集合。
2. 手动导入一份 JSON 数据（您可以自己准备一些常用菜品），并确保这些菜品的 JSON 数据中 **不要包含 `familyId` 字段**。系统在初始化时，会自动抓取没有 `familyId` 的菜品作为公共模板。

### 第六步：大功告成，开始体验！
在开发者工具的顶部工具栏，点击 **“清缓存 -> 全部清除”**，然后点击 **“编译”**。
系统会重置状态并自动带您进入【家庭点餐】的绿色引导页。点击“创建我的家庭厨房”，尽情享受自己部署的小程序吧！
