# 家庭点餐 (Family Food Ordering) - 微信云开发小程序

这是一个基于微信小程序云开发的全栈示例项目，旨在提供一个“家庭点餐”应用的完整实现。该项目从零开始构建，实现了从前端 UI 到后端数据库（云端）的完整闭环。

## 🌟 项目特点

- **纯原生微信小程序**：未使用任何第三方前端框架，原生实现高性能交互。
- **Serverless 云开发**：完全脱离传统后端服务器，使用微信云开发（CloudBase）管理数据源。
- **实时数据联机同步**：利用云数据库的 `.watch()` 能力，实现购物车/订单状态在多个客户端的毫秒级实时同步。
- **自动超级数据初始化**：内置了健壮的数据库初始化脚本，首次运行自动生成并分批安全写入 120 道详细菜品数据，避免网络超时。
- **零手动修改原则**：代码结构清晰，严格遵循模块化原则，立即可用。

## 📱 核心页面与功能

1. **首页 (`pages/index/index`)**
   - 包含搜索栏和菜品分类导航（特色、冷菜、热菜、汤）。
   - 双列网格布局展示菜品列表。
   - 支持从云数据库拉取数据并实现前端分类过滤。
   - 提供直接一键加入购物车功能（使用 `catchtap` 阻止事件冒泡）。

2. **菜品详情页 (`pages/detail/detail`)**
   - 顶部大图展示，详细的菜品名称、价格、描述。
   - 包含菜品用料列表和结构化的步骤时间轴（做法区）。
   - 具有数量调节器，支持修改数量并直接加入购物车。

3. **订单/购物车页 (`pages/order/order`)**
   - **魔法核心**：在 `onShow` 生命周期通过云数据库监听 `watch` 实现实时更新，无需手动刷新。
   - 列表展示已点菜品，并支持侧滑/按钮删除。
   - 底部固定结算栏，自动根据实时更新计算总价格。

4. **个人中心 (`pages/user/user`)**
   - 展示用户信息、快捷订单状态入口。
   - 提供地址、优惠券、设置等常规菜单项布局。

## 🛠️ 技术栈

- **前端**：WXML, WXSS, JavaScript, JSON (微信小程序原生规范)
- **后端/数据库**：微信云开发 (wx.cloud)
  - **集合(Collection)**: `dishes` (菜品库), `cart` (购物车)

## 🚀 快速启动

1. **导入项目**
   在微信开发者工具中，选择“导入项目”，目录选择包含 `project.config.json` 的根目录。

2. **修改云环境配置**
   在开发者工具顶部点击“云开发”开通云服务。并在 `miniprogram/app.js` 中将云环境 ID 替换为你自己的：
   ```javascript
   wx.cloud.init({
     env: '你的真实云环境ID', // 例: cloud1-d7gcfpwmc6468882a
     traceUser: true,
   });
   ```

3. **初始化数据库**
   首次编译运行时，小程序会自动执行 `miniprogram/db-init.js`，通过分块机制（10条一批，间隔 500ms）向你的云环境 `dishes` 集合注入 120 道带有用料和步骤详细信息的菜品数据。

4. **体验实时同步**
   使用两个手机预览小程序，或者在开发者工具打开“多账号调试”，在 A 账号加入购物车或删除菜品，B 账号的订单页面会自动实时更新！
